# Rules

Rules shared between projects. Before any work, read and follow these files, beside this one:

- `HOW-TO-USE-AND-EXTEND-RULES.md`: how to apply the rules, and how a lesson becomes one.
- `GENERAL-RULES.md`: rules for any project, in any language.
- `<LANGUAGE>-RULES.md`: rules for one language; read the file of each language the project is written in: `GO-RULES.md` for Go.
